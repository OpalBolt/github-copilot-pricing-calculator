# Split into an EU router calculator and a global model price calculator

The site grows from three tools to four. The router calculator is re-scoped as the EU Router Price Calculator at `eu-router-pricing.html`: Cortecs, EUrouter, and OpenRouter with their EU claims, the direct Claude, OpenAI, DeepSeek, and z.ai baselines kept visible with a no-EU-routing marker, and OpenCode Zen removed because it publishes no EU catalog. A new Model Price Calculator lists every Seller the build can query directly — routers, gateways, and first-party APIs — under ADR 0002's live-first-party rule. Both pages share one fetch layer: shared helpers plus per-source adapter modules, each source fetched once per build, with per-source failure isolation and the existing seven-day stale rule. A Seller without a live public source gets no row.
