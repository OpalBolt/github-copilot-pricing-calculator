# Select the default view from OpenRouter usage rankings

The Model Price Calculator's default view shows listings for the 20 most-used models, taken by walking OpenRouter's `rankings-daily` dataset (token totals summed over its 30-day window, fetched with a key) and keeping at most 3 models per creator. Ranked models match Seller listings by normalized slug equality — lowercase, creator prefix removed, trailing date and `:free` suffixes stripped, punctuation dropped so `4.5` and `4-5` compare equal; misses are visible and the page never claims two listings are the same model. The table stays flat and price-sorted with no grouping; comparisons happen through search, sort, and the tray. OpenRouter usage data selects rows only — every price still comes from its Seller (ADR 0002). A failed or keyless rankings fetch falls back to the previous build's selection, expiring after seven days, and never fails the build.
