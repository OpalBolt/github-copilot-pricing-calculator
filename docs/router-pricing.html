Router rows are model-level Router Prices recorded at build time; direct API rows use the provider's published token prices and are explicitly marked as not routed. EU routing means the documented mode of each router: Cortecs uses its eu_native=true catalog, EUrouter uses its baseline EU guarantee, and OpenRouter uses its EU regional catalog. OpenCode Zen does not publish an EU catalog. OpenCode Zen, OpenRouter, DeepSeek, and z.ai USD prices are converted with the unrounded ECB reference rate shown above. Calculations use unrounded values and display rounding only. When no cached-input price is published, the input rate is used as an estimate and marked with ⚠. This does not mean the router publishes or supports prompt caching. Fully free offers do not show this warning because the fallback cannot change their cost.
