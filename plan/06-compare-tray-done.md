# Compare tray

## Parent

`plan/plan.md` — Cortecs price calculator (sister site).

## What to build

Let a visitor pin a few models and read them side by side. A "+" control on each model row adds the model to a compare tray at the bottom of the page. The tray holds up to about five models and compares each at its cheapest price.

The tray mirrors the GitHub tool's compare surface. It shows the pinned models' prices and the configured budget figures together, so a visitor can read them at a glance. A visitor can remove a model from the tray.

See `plan/plan.md` under "UI" for the compare decision.

## Acceptance criteria

- [ ] A "+" control on each model row adds the model to the compare tray.
- [ ] The tray holds up to about five models.
- [ ] The tray compares each model at its cheapest price.
- [ ] A visitor can remove a model from the tray.
- [ ] The tray shows each pinned model's price and budget figures together.
